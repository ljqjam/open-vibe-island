# Open Island 第三方安装与配置指南

本指南面向拿到 `Open Island.dmg` 安装包的第三方用户，说明从安装到「在 Hi 内交互审批」全链路的完整配置步骤。

> 说明：**第 3 步**（钩子）决定「能否感知 Agent 事件」；**第 4、5 步**（Hi 配置）决定「能否在 Hi 收发并审批」。两条链路相互独立，缺一则对应功能失效。

## 1. 安装应用

- [ ] **1.1 拷贝安装包**：把 `Open Island.dmg` 发给对方，双击挂载，将「Open Island」应用拖入「应用程序」文件夹。
- [ ] **1.2 绕过门禁校验**（当前安装包为本地未签名版本）：首次打开若提示「无法验证」或「已损坏」，在终端执行

  ```bash
  xattr -dr com.apple.quarantine "/Applications/Open Island.app"
  ```

  或 右键应用 → 打开 → 确认打开。

  > ⚠️ 若要正式对外分发，建议先做开发者签名 + 公证（参考 `docs/release-signing.md`），对方即可免去此步。

- [ ] **1.3 启动应用**，确认菜单栏／刘海区出现 Open Island 图标。

## 2. 授予系统权限（用于跳回终端／编辑器）

- [ ] **2.1 辅助功能**：系统设置 → 隐私与安全性 → 辅助功能 → 允许 Open Island。
- [ ] **2.2 自动化**：首次跳转终端时会弹窗请求控制「终端／iTerm」等，点击允许。
- [ ] （可选）需要精准跳转或按键注入时，确保上述两项都已勾选。

## 3. 安装 Agent 钩子（在应用内「设置」中完成）

- [ ] **3.1 打开 设置 → 集成／钩子 页面。**
- [ ] **3.2 为要使用的 Agent 安装钩子**（Claude Code／Codex／Gemini／Cursor／OpenCode 等）。
- [ ] **3.3 重启对应 Agent**（如 Claude Code）让钩子生效。
- [ ] **3.4 验证**：Agent 运行时，刘海区能显示会话状态。

## 4. Hi 开放平台「应用号」配置（交互审批的前提）

- [ ] **4.1 在 Hi 开放平台创建 应用 + 机器人（应用号）。**
- [ ] **4.2 记录三项凭证**：应用 ID（appId）、应用密钥（appSecret）、应用号 ID（asnId）。
- [ ] **4.3 订阅发消息接口权限**：`redcity:asn.asnSendMessageToPerson:v2`。
- [ ] **4.4 配置事件订阅（交互审批必需）**：应用号 AI → 事件订阅 → 选择 **WebSocket** → 订阅 `asn:bot.chat.message:v1` → **点击发布**。
- [ ] **4.5 获取接收人账号 ID**：要接收通知的那个 Hi 账号（如 `xxx@xiaohongshu.com`）。
- [ ] （可选）**4.6 创建卡片模板**，拿到模板 ID（schemaId）——想要带按钮的卡片而非纯文本时才需要。

## 5. 在应用内填写 Hi 设置

- [ ] **5.1 设置 → Hi IM → 打开「Hi IM 通知」开关。**
- [ ] **5.2 填写接口凭证**：应用 ID、应用密钥。
- [ ] **5.3 填写推送目标**：应用号 ID（asnId）、接收人账号 ID。
- [ ] **5.4 打开「在 Hi 内审批（WebSocket）」开关。**
- [ ] （可选）**5.5 填写卡片模板 ID**（留空则使用纯文本审批）。
- [ ] **5.6 点击「发送测试消息」**，确认 Hi 能收到。

## 6. 端到端验证

- [ ] **6.1 在 Agent（如 Claude Code）触发一个需要权限的操作。**
- [ ] **6.2 确认 Hi 收到权限请求消息。**
- [ ] **6.3 在 Hi 回复 `y` 批准／`n` 拒绝**（有多条待审批时，用 `y 短码` 指定）。
- [ ] **6.4 确认 Agent 被放行并继续执行。**

## 关键依赖提醒

- 交互审批的核心是 **4.4 事件订阅必须发布** + **5.4 开关必须打开**，缺任一则回复 `y` 无效。
- 凭证保存在本地偏好设置中，更换电脑需重新填写。
- 钩子采用「失败即放行」策略：Open Island 未运行时，Agent 不受影响正常执行。
